# Brand and mascot sources

Original artwork supplied by the project team. The web app uses optimised copies in `apps/web/public/landing/`.

| File | What it is | Where it is used |
|---|---|---|
| `cag-logo-official.png` | Official CAG emblem lockup (with "Supreme Audit Institution of India" text) | Trimmed to `public/landing/cag-logo.png` (header plate); the round seal is cropped to `cag-seal.png` (badge on the mascot's pocket) |
| `bhashini-logo-official.png` | Official BHASHINI logo | Trimmed to `public/landing/bhashini-logo.png` |
| `sahayak-mascot-master.png` | Sahayak, transparent background, 1024 × 1536 | `sahayak-half.webp` (waist-up crop with the CAG seal on the pocket), `sahayak-avatar-{64,128,256}.png` (circular head crops) |
| `sahayak-character-sheet.png` | Turnaround, expressions, poses, colour palette, avatar sizes | Reference only, for future poses/animation |

Never redraw or approximate the logos or the mascot. The landing background video is `apps/web/public/landing/hero.mp4` (5 MB; compress for production).
